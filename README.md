# Wyatt Ades - Personal Site

## Technologies

- Typescript
- React
- Next.js
- Lucide icons
- Three.js w/ react-three-fiber
- Cannon.js physics engine

## System tests

Run `pnpm test:system` to build the production app and test the wrecking-ball
physics in a headless browser. If Chrome is not installed, first run
`pnpm exec puppeteer browsers install chrome`.
